# 资政大模型 — 检索质量评估报告（C3）

> 对比 **DC-RAG（类别→文档→文本块 三级检索）** 与 **简化 RAG（扁平 top-k 检索）** 的检索质量。
> 更新日期：2026-09-08

---

## 1. 评估设置

| 项 | 说明 |
| --- | --- |
| 评测集 | `data/eval/eval_questions.jsonl`，12 个问题，覆盖国家级/省级/市级/区级与不同主题（经济目标、就业、产业、城市更新、财政、港口、科学城、金融、制造业等） |
| 黄金答案 | 每个问题标注期望命中的文档（gold_doc_id） |
| 知识库 | 8 类 / 160 篇有效文档 / 15546 文本块（BGE-small-zh-v1.5，512 维） |
| 指标 | 文档级 Recall@3、MRR@3；块级 Recall@3（返回 top-3 文本块所属文档含 gold 即命中） |
| 查询处理 | 两者使用相同 BGE 查询向量；DC-RAG 额外使用问题中的确定性年份/地域元数据约束，扁平 RAG 保持纯向量基线 |

## 2. 评估结果

### 2.1 文档级

| 方法 | Recall@3 | MRR |
| --- | --- | --- |
| DC-RAG（top_c=2, top_d=3） | 12/12（100%） | 0.958 |
| 简化 RAG（top_d=3） | 7/12（58%） | 0.361 |

> 元数据约束解决了同地区跨年份报告之间的竞争，DC-RAG 文档级 Recall@3 提升至 100%。

### 2.2 块级（核心差异）

| 方法 | 块级 Recall@3 |
| --- | --- |
| **DC-RAG** | **12/12（100%）** |
| **简化 RAG** | **2/12（17%）** |

> **DC-RAG 块级命中率优于简化 RAG（+10 题，83 个百分点）。**

**差异原因**：DC-RAG 先经“类别→元数据约束→文档”筛选缩小候选，再在相关文档内检索文本块；简化 RAG 直接在全库 15546 块中取 top-3，结果容易被不同年份的高相似内容抢占。

## 3. 优化历程（从 17% → 100%）

| 优化项 | 效果 |
| --- | --- |
| 初始：文档向量=块均值，查询无前缀 | 文档级 Recall@3 仅 2/12（17%） |
| 文档向量改用 **LLM 摘要向量** | 文档级 Recall@3 提升至 7/12（58%） |
| 查询加 **BGE 检索指令前缀** | 稳定检索效果 |
| 聚类细化 **k=3 → k=8**（按区域划分） | 类别筛选更有区分度 |
| 引入年份/地域约束及单文档块数限制 | 文档级、块级 Recall@3 均提升至 12/12（100%） |

## 4. 结论

1. 当前 12 题评测中，DC-RAG 文档级和块级 Recall@3 均为 100%，高于扁平基线。
2. 年份和地域约束对政府年度报告尤其重要，能有效消除同源、跨年份文本的语义竞争。
3. 单文档最多返回两个块，避免某一同年报告垄断全部上下文，同时保留多块证据。
4. 评测集仅 12 题，结果用于回归验证，不应表述为统计学“显著”；后续需扩充到至少 50—100 题。

## 5. 复现

```bash
# 重建知识库（块向量缓存复用）
python -m src.retrieval.build_kb
# 运行评估
python -m src.retrieval.evaluate --top-c 2 --top-d 3 --top-k 3
```
